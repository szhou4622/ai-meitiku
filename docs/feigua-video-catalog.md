# 带货视频分类内置目录

`electron/feigua-video-catalog.json` 是带货视频关键词设置的离线初始目录。用户首次打开、旧状态未缓存目录或目录刷新失败时，仍可选择分类；已有有效缓存优先使用。登录后自动更新目录，采集时必须回读实际筛选路径一致，内置目录不代表账号拥有筛选权限。

来源：2026-10-02，在本项目开发版的原飞瓜持久会话中，从菜单进入“带货视频库”，只读提取页面“带货品类”和“视频标签”控件已加载的 options。只保留名称与父子关系，不包含账号、会话、权限状态、原始 ID、指标或用户记录。

- 带货品类各级节点数：22 / 54 / 620 / 6261 / 744，共五级。
- 视频标签各级节点数：29 / 140 / 424，共三级。
- 不把带货视频目录当作 BGM 目录：音乐、话题当前目录只有两级。
- 文件为 UTF-8 紧凑 JSON，加一个末尾换行；不含末尾换行的规范 JSON SHA-256：`e6bea7f0e60aadf353c9d791ef2548ae0d079806ddbd1b77690152a0634370e2`。

真实适配器复测返回的规范化目录与内置文件逐项一致。该页面的视频标签 value 是字符串 ID，而带货品类和排行榜控件使用数组；适配器兼容两种类型，并拒绝未知 ID。

后续更新应从同一来源重新读取完整目录，运行 normalizeVideoOptions 校验，比较增删及层级差异后替换快照并更新此记录。不可用猜测目录或其他榜单的分类树替代。真实分类采集仍受飞瓜账号权限约束。
