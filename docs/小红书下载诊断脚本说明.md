# 小红书下载诊断脚本

将以下两个文件放在同一文件夹后，只需双击一次 `运行小红书诊断.cmd`：

- `运行小红书诊断.cmd`
- `collect-xhs-download-diagnostics.ps1`

脚本兼容 Windows PowerShell 5.1 和 PowerShell 7，无需管理员权限。完成后桌面会出现
`AI媒体库-小红书诊断-日期时间.zip`，只发送这一份 ZIP 即可。

脚本自动收集客户端版本、签名状态、打包的小红书后端版本及校验值、最近 100 条小红书
任务的脱敏错误、链接是否携带 `xsec_token`、登录数据文件是否存在、输出目录可用性以及
DNS、TCP 443 和匿名首页连通性。它不会重试作品下载，也不会导出 Cookie 内容、激活码、
`xsec_token` 值、完整作品链接或用户素材。

如所在网络不允许访问小红书，可在 PowerShell 中使用以下命令跳过联网检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\collect-xhs-download-diagnostics.ps1 -SkipNetwork
```
