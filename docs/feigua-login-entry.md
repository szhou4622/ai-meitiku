# 热点采集登录入口与代理工作台

在热点采集页的登录状态旁填写「登录入口网址」，点击「保存网址」，再点击「打开登录入口」。支持 HTTP / HTTPS 地址和端口；地址变更时可直接修改。空配置不会默认打开飞瓜官网，旧安装首次使用也需配置入口。

网址仅保存到当前电脑已有的 `feigua-trends/state.json`，重启后恢复。项目中不预置或提交真实入口、账号、密码或登录会话。修改入口会结束旧登录窗口并重置登录状态，保留已有采集结果和持久会话；保存失败则保留原配置与状态。

登录窗口先访问保存的入口，用户在该入口完成登录并进入飞瓜工作台。允许入口的同源页面、已有飞瓜域名和微信登录域名导航。入口页面通过 `window.open` 发起的同协议、同主机跨端口跳转，也会在当前窗口打开，并仅放行本次选择的目标端口后续导航；代理页不能自行增加端口信任，修改入口会清除临时信任。其他域名需经后续证据确认后适配。入口及未核验的代理页面不会运行飞瓜采集脚本，也不会仅凭入口登录成功就显示飞瓜已登录。只有识别到飞瓜工作台后才允许自动采集。

所选网关进入 `/app/` 后，以已挂载的飞瓜 API 客户端、个人中心链接和可见工作台菜单核验登录，兼容个人中心收进下拉菜单的新版界面。SPA 尚在挂载时等待完成，避免误报登录过期。只有核验成功的网关源允许采集；修改网址清除该信任。登录复查、菜单导航、请求与来源校验均使用本次网关，保留真实来源地址。

程序把已核验工作台的源地址作为 `workspaceHint` 保存到已有本机状态文件，与完整登录入口配置绑定，只保存入口和源地址，不保存带签名的登录链接。该字段只用于定位复查页面，不能证明已登录或直接放行采集。重启后点击「保存并刷新」会使用原持久浏览器会话加载该工作台并重新核验；有效则采集本次选择的 BGM / 话题，失效或重定向登录页则明确提示点击「打开登录入口」重新登录。网络或存储错误显示检查失败，不冒充登录失效。已有结果不会遮挡过期提示。

升级时可从本机已通过接口校验的历史结果推导同服务器的复查地址，仍需实时核验。修改入口明确清空该字段，重启也不会从旧结果复活已清除的地址。分类先可靠保存，再检查会话；旧结果在失败时保留原分类标签。

本分支从 main 创建，现已整合 PR #4 的榜单接口采集与校验代码，保留登录网址配置。榜单字段来自当前页面实际请求的接口响应：匹配本组关键词、日期、分类与排序，验证第一页、排名及权限后才保存；不使用截图、DOM 表格或示例数据补齐，失败保留以前结果。

## 入口账号密码记忆

程序在配置入口的可见登录表单中记忆最后输入的账号密码，掉线或重新打开入口时回填空字段，由用户点击登录。遵循页面「记住密码」勾选：取消后撤销程序保存的凭据；已填写的值不被旧密码覆盖，更换账号不回填旧账号密码。之前版本未保存的密码无法恢复，更新后首次需要输入一次。

凭据仅通过现有 `LicenseSecureStore` 和 Electron `safeStorage` 保存到本机独立的 `feigua-login-credentials.v1.bin`，不进入热点 JSON、公开状态、日志或 Git。绑定完整入口配置，改地址后不向新入口发送旧密码。系统加密不可用时提示手动输入并保留原文件，不回退为明文。

登录窗口保留 sandbox / contextIsolation 和禁用 Node 的边界。专用 preload 仅向隔离世界 47 提供私有捕获通道，网页和媒体库主界面都不能访问该接口。主进程再次校验窗口、主框架和入口源，使用递增序号忽略旧快照。点击或提交登录时同步确认捕获，再排队加密，避免导航销毁页面导致最后输入丢失；不自动提交登录表单。

## 登录后立即启动采集

登录确认后的自动批次记录 `trigger: login`，先启动首组取数，不再先导航到 BGM 和带货视频页面刷新目录。分类目录从该组已经访问的页面读取、随结果更新；无关键词时仍可用已有的内置视频目录。用户存在未保存草稿时，仍只刷新目录，避免采集错误设置。

网络空闲等待只跟踪当前窗口的主页面及四个榜单接口请求；日志、广告、其他窗口或无关接口不延长该等待。仍回读页面加载与实际筛选状态，API 参数、日期、排名、响应及落盘校验保持不变。界面显示当前组次，待执行的组显示「等待采集」，不会提前声称正在刷新。

## 最新结果展示与失败重试

结果区已移除采集批次选择，固定显示每个模块、关键词最新可用结果。每组数据通过校验并保存后自动替换；采集中或重试时保留原有结果及其真实分类、时间，明确显示等待、自动重试或未更新状态。

旧逻辑有控件操作等待，但没有整组取数的网络失败重试。现按失败的组自动重试：识别到网络超时、断网或临时服务器 500 / 502 / 503 / 504 时，分别等待 10 秒和 30 秒再取数，总计最多 3 次尝试。每次重新导航、捕获并核验本组的新请求；不重采已成功的组，不改变该组关键词与分类快照。

登录失效、权限不足、额度耗尽、频率限制、页面或数据校验不通过、本机保存失败不盲目重试。登录失效提示重新登录；额度或频率限制停止后续请求；权限及校验问题保留旧结果。重试状态先落盘，保存失败不发下一次请求。停止采集可立即取消退避等待；重启把未完成重试标记中断，不擅自重复已记录任务。
