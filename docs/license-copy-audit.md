# 客户端授权提示措辞盘查

盘查日期：2026-09-16

范围：AI媒体库客户端的软件许可证文案，包括离线横幅、进入软件前的拦截页、激活失败提示、状态徽标、设置页授权管理、toast，以及千川功能读取软件许可证时产生的提示。经产品确认，本轮只修改原清单第 2、3、5、7、9、10 条；其余 12 条保留原文并记录暂不修改的理由。

## 已核对、当前无需调整

- 正常离线横幅：`离线模式 · 功能正常可用，联网后将自动完成授权验证（剩余 N 天）`，已先回答“还能不能用”，不会暗示时间卡到期。
- 第 8 天专用拦截文案：`当前无法完成联网授权验证，请检查网络、VPN 或防火墙。` / `您的授权未失效，联网后将自动恢复使用。`，仅在离线宽限结束且缓存中的时间卡到期日仍在未来时显示。
- 状态徽标 `等待联网验证`：描述的是待完成的动作，不把网络问题说成授权失效。
- `已到期`、`已禁用`：只在服务器明确返回 expired/disabled/revoked/banned 时显示，语义与状态一致。
- 设置页说明 `授权信息以服务器返回为准；激活码和设备凭证加密保存在当前电脑。`：事实清楚，没有重新购买暗示。
- 隐藏重置入口说明 `不会删除激活码或设备凭证`：已明确保护范围。
