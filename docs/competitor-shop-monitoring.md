# 竞对店铺周数据采集

开发分支：`codex/competitor-shop-collection-20261016`，基于第三方版和官方版的共同基线 `994715e`。本分支只新增共同的采集能力，保留现有登录实现，暂不合并两条版本线。

## 使用范围

原有 BGM、话题、全网热点和关键词视频采集及其设置、结果保持完整展示，店铺监控作为下方新增区块同时存在，不用页签互斥隐藏。上方提供快捷滚动按钮，两块共用现有飞瓜登录，分别操作采集。

在「热点采集」上方的「采集设置」内管理监控店铺，与 BGM / 话题分类、关键词配置并列。输入店铺名称，搜索后确认具体结果，点击「添加并采集」；刷新和移除操作也在此处。下方「竞对店铺监控结果」用于切换店铺、历史周和查看数据。最多监控 10 家，按飞瓜 ShopId 区分同名店铺。移除监控不访问飞瓜，也不删除原有周历史；重新添加同一店铺可继续查看历史。

「添加并采集」与手动刷新会先核对飞瓜的关注列表。尚未关注时，在账号剩余名额允许的情况下，同步关注该已确认的店铺，再重新读取关注列表确认成功，然后采集周数据。已关注的店铺不重复添加。界面明确提示同步会占用飞瓜关注名额；本地移除监控保留飞瓜关注，不自动删除任何来源记录。后台每日更新只读取已关注店铺，来源关注被移除后提示用户手动刷新同步。

关注成功不等于来源数据准备完成。通过来源列表的 `FocusId` 调用正常详情入口 `/api/v3/focusshopdetails/GetFocusShopBaseData`，核对返回 `ShopId` 和 `DynamicDataFetchFinish`。仅在准备完成时读取完整周数据；准备状态为 false 时显示「飞瓜正在初始化」，不把间歇返回的空值或 403 当成完整结果。等待队列本地持久化，以 1、3、5 分钟逐步间隔检查，之后保持 5 分钟间隔；数据就绪后自动采集，不重复新增关注。应用需运行且登录有效，重启可恢复等待；移除监控、主动取消或登录失效后停止该等待任务。等待期间已有周记录保留，本周未经重新核验的记录不作为当前完整结果展示。

品类 Top5 与监控店铺通过同一日期模块、同一北京时间 07:00 时点更新；共用飞瓜会话顺序执行。两者默认统计北京时间本周周一至昨天，保留飞瓜原始销售额、销量区间，不对区间自行求和。周一尚无已结束日期，不采集当天或虚构本周结果，仍可查看历史周。应用运行时每天北京时间 07:00 后检查一次；手动已经成功更新的店铺不重复自动采集，错过时间后启动应用可补采。失败保留已保存周数据，可手动重试。

## 数据与展示

- 周汇总与逐日明细：销售额、销量、带货商品、带货视频、带货直播、带货达人、上架商品、信息变更商品、首次合作达人。
- 小店动态：商品上架节奏、上架商品 Top10、商品信息变更及首次合作达人。保留来源提供的达人名、粉丝数、首次带货视频或直播标题、变更类型和文字前后值。
- 动态按店铺、周起止日期和三类筛选分页读取；保存完整列表后可本地筛选，默认每页 10 条，允许选择 20、50、100 条、上一页 / 下一页和跳转页码。切换店铺、周、筛选或每页条数时回到第一页；数据更新后页码自动限制在有效范围。来源数据超过安全读取上限或分页重复、缺页、统计数变化时停止该店保存，不把部分列表标成完整成功。
- 每店保留最近 52 个有记录的周；本周持续更新同一条记录。切换店铺、历史周和本地动态筛选均不访问飞瓜。

## 登录、权限与接口边界

复用当前版本的飞瓜浏览器及登录会话，不新增独立账号、密码或登录方式。店铺搜索使用页面实际发出的只读 POST `/api/v1/shopsearch/list`；周汇总、每日列表、动态汇总、上架趋势、上架 Top10、动态筛选目录及动态列表使用 `electron/feigua-shop-api.mjs` 中的已观察白名单接口。

飞瓜「关注的小店」数据受账号权限及关注状态约束。新增店铺只保存到本地而未同步来源关注，会使周接口返回 403。手动采集现在先核对 `/api/v1/focus/shop/list`，检查 `/api/v1/focus/shop/getFocusCount` 的剩余名额，仅通过正常官网界面已观察到的 POST `/api/v1/focus/shop/add`、固定默认分组 `groupId: 0` 和已确认的 `shopId` 同步关注，再回读核验。同名搜索未确认、列表分页不完整、名额未知或不足时不新增关注；失败或超时不盲目重发，下次手动重试先重新核对来源列表。不购买名额、不删除或移动已有关注、不把真实权限拒绝或示例数据当作零。真实零值会正常保存，未提供的字段显示来源未提供。

主进程验证每次新请求的来源、店铺、周起止日期及分页。来源指标只保存页面显示字符串，不落盘来源接口的精确隐藏估算值、签名地址、令牌或 Cookie。没有截图、OCR 或 DOM 表格采集回退。店铺与原热点采集共用串行门禁；停止可覆盖登录等待、源请求、分页及保存前阶段，迟到响应不会覆盖旧记录。

本地独立保存于用户数据目录 `feigua-shops/state.json`；不修改热点数据文件。先完成可靠保存再发布新结果，保存失败保留原文件。重启将未完成任务标记中断，不自行重放；损坏数据不重置为空文件。
