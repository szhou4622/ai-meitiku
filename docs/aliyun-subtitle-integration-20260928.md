# 阿里云去字幕实现与验收记录

2026-09-28。选择视觉智能开放平台（VIAPI）的视频生产能力，非 IMS。用户已确认该路线。

## 实现范围

- 侧栏「阿里云去字幕」，设置末尾独立「阿里云去字幕」。
- 设置单列铺满内容宽度，首次使用按「开通服务 → 获取密钥 → 粘贴保存」引导，保存后可直接进入视频页；官方链接支持系统/内置浏览器。
- 独立密钥与任务加密文件，不改写火山引擎或 MiniMax 设置。
- MP4 文件检测、底部 25% 默认区域及自定义归一化矩形、上传费用确认。
- 官方 SDK `eraseVideoSubtitlesAdvance` 自动处理本地文件上传，不要求用户填写 OSS。
- `RequestId` 作为异步 `JobId` 查询；完成后立即流式下载、检查文件长度和 MP4 元信息、计算 SHA-256。
- 成片独立文件名，可预览、打开目录、加入媒体库。加入标记在媒体库索引保存成功后写入。
- 重启只恢复已知任务的查询，不重复提交收费任务；提交结果不明时提示核实，可填写找回的 RequestId。
- 查询/下载失败只恢复原任务；不会自动重新调用收费擦除接口。
- 内置窗口隔离会话、无 Node/应用 preload、HTTPS 阿里云域名导航白名单。

## 易用性修订

- 接入设置解释密钥用途、官方对应名称和每一步操作。保存与身份检查合并为一个按钮；保存后提供「下一步：选择视频」。
- 视频页按「选视频 → 确认字幕位置 → 开始处理」展示；鼠标拖框选择字幕，百分比参数放在默认折叠的高级设置。
- 默认保存到系统下载目录下的「阿里云去字幕」，首次提交时建立该目录；仍可更换目录。
- 预计费用优先展示当前视频的估算值。仍需用户确认上传与费用后才能提交。
- 未提交真实付费视频，云端验收状态不变。

## 完成后自动同步媒体库

- 提交前提供「完成后自动同步到媒体库」，默认不勾选，选择写入每条任务记录。历史任务不会被追溯自动导入。
- 应用级同步器在媒体库加载完成后处理已下载的勾选任务；切换功能页面不影响同步，重启后继续处理待同步任务。
- 先持久化媒体索引，再记录 importedAt；失败单独显示「重试同步」，不改变云端任务状态或重复收费提交。
- 原视频下拉框排除任务记录中的输出路径、阿里云去字幕集合成片及已删除/不可用素材，不根据文件名猜测。没有原视频时提示并禁用下拉框。
- 自动同步保持当前媒体库筛选，不切换用户所在页面。已有成片的手动加入入口继续保留。
